# 예약 재시작과 전원 설정

> 분류: Windows·자동화 · 최근 갱신: 2026-09-30

## 한 줄 요약
PC를 자동으로 재시작한 뒤 로그인된 상태(잠금)로 돌려놓으려면 `shutdown /g`와 ARSO를 쓰고, 원격으로 계속 쓰려면 절전에 들어가지 않게 전원 설정을 바꾼다.

## 내용
### 꺼진 PC는 스스로 켜지지 못한다
- 완전히 꺼진 PC를 켜려면 PC 밖의 수단이 필요하다: BIOS 예약 부팅, Wake-on-LAN, 스마트 플러그 + BIOS 전원 복구 설정, IP-KVM, vPro/AMT.
- 그래서 "매일 깨끗한 상태로 시작"이 목적이면 종료 후 부팅이 아니라 **재시작**으로 구현한다.

### shutdown /g 와 ARSO
- `shutdown /g`는 재시작한 뒤 등록된 애플리케이션을 다시 실행하는 재시작이다.
- ARSO(Automatic Restart Sign-On)가 켜져 있으면 재시작 후 마지막 사용자로 자동 로그인하고 **화면은 잠긴 상태**로 올라온다. 로그인 세션이 있으므로 "로그온 시 실행" 작업과 시작 프로그램이 돈다.
- 설정 위치: 설정 → 계정 → 로그인 옵션 → "업데이트 또는 다시 시작 후 로그인 정보를 사용하여 자동으로 설정 완료".
- netplwiz/Autologon 방식의 완전 자동 로그인은 비밀번호가 저장되고 잠금 없이 바탕화면이 열리므로 보안상 권하지 않는다.

### 사용 중일 때는 재시작하지 않기
- 재시작 전에 입력 없는 시간이 일정 시간 이상인지 확인하고, 사용 중이면 건너뛴다.
- `shutdown /g /t 120`처럼 유예 시간을 두면 그 안에 `shutdown /a`로 취소할 수 있다.
- 재시작 후 작업은 "예약 재시작으로 올라온 경우"에만 돌도록 표시 파일을 남기고 유효 시간(예: 1시간)을 둔다. 사용자가 직접 재부팅했을 때 같은 동작이 실행되지 않게 하기 위해서다.

### 절전과 원격 사용
- 최신 대기 모드(S0 저전력 유휴)를 쓰는 노트북은 절전에 들어가면 앱이 거의 멈춘다. 원격으로 붙어야 하는 프로그램은 응답하지 못한다.
- 화면 잠금(Win+L)과 화면 꺼짐은 영향이 없다. 로그인 세션과 Wi-Fi가 유지되고 작업 스케줄러도 잠금 상태를 로그온으로 본다.
- 전원 연결 시 절전 안 함, 덮개를 닫아도 동작 안 함으로 설정하면 덮개를 닫고 잠가 둔 채로 쓸 수 있다.

## 예시
```powershell
# 재시작 (2분 유예, 취소는 shutdown /a)
shutdown /g /t 120

# 전원 연결 시 절전 안 함
powercfg /change standby-timeout-ac 0

# 전원 연결 시 덮개를 닫아도 아무 동작 안 함
powercfg /setacvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0
powercfg /setactive SCHEME_CURRENT

# 지원하는 절전 상태 확인 (S0 저전력 유휴 여부)
powercfg /a
```

## 주의할 점
- ARSO는 디스크 암호화나 조직 정책에 따라 동작하지 않을 수 있다. 적용 전에 `shutdown /g /t 0`으로 자동 로그인과 잠금이 되는지 직접 확인한다.
- 스토어(MSIX) 앱은 실행 파일 경로 대신 `shell:AppsFolder\<패키지 ID>!<앱 ID>` 형식으로 실행한다.
- 배터리 사용 시 설정은 그대로 두는 편이 안전하다. 가방 안에서 켜진 채로 있으면 과열된다.
- 재시작 후에는 이전에 떠 있던 프로그램의 세션이 복원되지 않는다. 필요한 프로그램은 재시작 후 작업에서 다시 실행한다.
