# 작업 표시줄 아이콘에 계단식 메뉴 붙이기

> 분류: Windows·자동화 · 최근 갱신: 2026-10-28

## 한 줄 요약
Windows 11 작업 표시줄에는 아이콘을 눌러 하위 메뉴를 펼치는 기능이 없으므로, 폴더 구조를 메뉴로 띄우는 작은 WinForms 프로그램을 Windows에 기본으로 있는 `csc.exe`로 빌드해 작업 표시줄에 고정한다.

## 내용
### 기본 기능과 외부 프로그램
- **점프 목록**: 아이콘을 우클릭하면 고정 항목이 나온다. 왼쪽 클릭이 아니고 한 단계 목록뿐이다.
- **도구 모음(New toolbar)**: Windows 10까지는 폴더를 작업 표시줄 도구 모음으로 넣으면 계단식 메뉴가 됐지만 Windows 11에서 없어졌다.
- 외부 프로그램: Taskbar Groups(한 단계 그룹 팝업), ExplorerPatcher(Windows 10식 작업 표시줄 복원, 작업 표시줄 전체가 바뀜).

### 직접 만들기
- .NET Framework 4.x는 Windows에 기본으로 들어 있고 C# 컴파일러 `csc.exe`도 함께 있다(`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`). 별도 설치 없이 exe를 만들 수 있다. PowerShell 스크립트로 만들면 기동에 1초쯤 걸려 메뉴가 늦게 뜬다.
- 프로그램은 실행되자마자 마우스 위치에 `ContextMenuStrip`을 띄우고, 항목을 고르거나 바깥을 누르면 끝난다. 창은 보이지 않게 둔다.
- 메뉴 구성은 **폴더 구조**로 둔다. 폴더 안의 바로가기(.lnk)·인터넷 바로가기(.url)·파일이 항목, 하위 폴더가 하위 메뉴가 된다. 다시 빌드할 필요 없이 폴더만 고치면 다음 실행에 반영된다.
  - 순서: 이름 앞에 `10_`, `20_` 번호를 붙이고 화면에는 번호를 빼고 보인다.
  - 구분선: 이름이 `---`인 빈 파일(`40_---.txt`).
  - 항목 넣기: exe·폴더는 Alt를 누른 채 끌어다 놓아 바로가기를 만들고, URL은 브라우저 주소창 왼쪽 자물쇠 아이콘을 폴더로 끌어다 놓는다.
- 작업 표시줄 고정: exe를 우클릭 → "작업 표시줄에 고정"(Windows 11은 "더 많은 옵션 표시" 안에 있을 수 있음). exe를 다른 폴더로 옮기면 고정 아이콘이 끊기므로 다시 고정한다.

## 핵심 코드
### 1) 폴더를 메뉴로 띄우는 프로그램 (TrayMenu.cs)
```csharp
// 바꿔야 할 곳: 메뉴 폴더 위치
using System; using System.Drawing; using System.IO; using System.Linq;
using System.Text.RegularExpressions; using System.Windows.Forms; using System.Diagnostics;

static class TrayMenu {
    static readonly Regex Order = new Regex(@"^\d+_");

    [STAThread]
    static void Main() {
        Application.EnableVisualStyles();
        string root = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "Menu");
        var menu = new ContextMenuStrip();
        Fill(menu.Items, root);
        menu.Items.Add(new ToolStripSeparator());
        menu.Items.Add("메뉴 편집 (폴더 열기)", null, (s, e) => Process.Start("explorer.exe", root));
        menu.Closed += (s, e) => Application.Exit();          // 고르거나 바깥을 누르면 종료

        var host = new Form { ShowInTaskbar = false, FormBorderStyle = FormBorderStyle.None,
                              Size = new Size(1, 1), StartPosition = FormStartPosition.Manual,
                              Location = new Point(-2000, -2000) };
        host.Shown += (s, e) => { host.Activate(); menu.Show(Cursor.Position, ToolStripDropDownDirection.AboveRight); };
        Application.Run(host);
    }

    static void Fill(ToolStripItemCollection items, string dir) {
        var entries = Directory.GetDirectories(dir).Concat(Directory.GetFiles(dir))
                               .OrderBy(p => Path.GetFileName(p), StringComparer.CurrentCultureIgnoreCase);
        foreach (var path in entries) {
            string name = Order.Replace(Path.GetFileNameWithoutExtension(path), "");
            if (name == "---") { items.Add(new ToolStripSeparator()); continue; }
            if (Directory.Exists(path)) {
                var sub = new ToolStripMenuItem(Order.Replace(Path.GetFileName(path), ""));
                Fill(sub.DropDownItems, path);                // 하위 폴더 = 하위 메뉴
                items.Add(sub);
            } else {
                string target = path;
                Image icon = null;
                try { icon = Icon.ExtractAssociatedIcon(path).ToBitmap(); } catch { }
                items.Add(new ToolStripMenuItem(name, icon, (s, e) => Process.Start(target)));
            }
        }
    }
}
```

### 2) 기본 컴파일러로 빌드 (PowerShell)
```powershell
$csc = "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe"
& $csc /nologo /target:winexe /out:TrayMenu.exe /win32icon:menu.ico `
       /r:System.Windows.Forms.dll /r:System.Drawing.dll TrayMenu.cs
New-Item -ItemType Directory -Force -Path .\Menu\10_도구 | Out-Null    # 예시 메뉴 폴더
```

### 3) 메뉴 폴더에 항목 만들기 (PowerShell)
```powershell
$ws = New-Object -ComObject WScript.Shell
$lnk = $ws.CreateShortcut("$PWD\Menu\10_도구\메모장.lnk")
$lnk.TargetPath = "$env:WINDIR\System32\notepad.exe"; $lnk.Save()
Set-Content "$PWD\Menu\20_문서 사이트.url" "[InternetShortcut]`r`nURL=https://example.com/"
New-Item "$PWD\Menu\30_---.txt" -ItemType File -Force | Out-Null     # 구분선
```

## 주의할 점
- 개인 메뉴 폴더에는 내부 주소나 개인 경로가 들어가므로, 소스를 저장소에 올릴 때는 메뉴 폴더와 빌드 결과물(exe, 아이콘)을 `.gitignore`에 넣고 빌드 스크립트와 예시 생성 스크립트만 올린다.
- 메뉴가 뜨는 위치와 바깥 클릭으로 닫히는지는 작업 표시줄에 고정한 상태에서 직접 눌러 확인해야 한다. 숨은 창을 먼저 활성화하지 않으면 바깥을 눌러도 메뉴가 안 닫히는 경우가 있다.
