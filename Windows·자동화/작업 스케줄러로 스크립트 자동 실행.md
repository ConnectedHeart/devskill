# 작업 스케줄러로 스크립트 자동 실행

> 분류: Windows·자동화 · 최근 갱신: 2026-09-30

## 한 줄 요약
관리자 권한이 필요한 스크립트는 "최고 권한" 작업으로 한 번 등록해 두면 UAC 창 없이 실행할 수 있고, 입력 없는 시간 감지나 창 없는 실행에는 각각 조건이 있다.

## 내용
### UAC 창 없이 관리자 스크립트 실행
- 관리자 권한으로 "최고 권한으로 실행" 작업을 등록한다(트리거 없는 수동 작업도 가능).
- 일반 사용자는 `schtasks /run /tn "<작업 이름>"`만 실행한다. 바로가기로 만들어 두면 클릭 한 번으로 실행된다.
- 작업이 실행하는 스크립트는 일반 사용자가 수정할 수 없는 폴더(예: `C:\ProgramData\<폴더>`)에 복사하고, 그 폴더를 관리자와 SYSTEM만 수정할 수 있게 권한을 제한한다. 관리자로 실행되는 스크립트를 일반 사용자가 고칠 수 있으면 권한 상승 구멍이 된다.
- 작업은 복사본을 실행하므로 원본 스크립트를 고치면 다시 설치(복사)해야 반영된다.

### 입력 없는 시간(idle)을 재는 작업
- 마지막 입력 시각은 로그인 세션 안에서만 잴 수 있다. 작업을 "사용자가 로그온한 경우에만 실행"으로 등록한다.
- 화면 잠금 상태도 로그온으로 취급되어 작업이 계속 실행된다.
- 놓친 실행을 PC가 켜질 때 한 번 실행하는 옵션("예약된 시작 시간을 놓친 경우 가능한 대로 빨리 작업 시작")을 켜 둔다.
- 작업은 재부팅 후에도 유지된다.

### 창이 뜨지 않게 주기 실행
- 몇 분마다 도는 PowerShell 작업은 콘솔 창이 깜빡인다. `conhost --headless powershell ...`로 실행하면 창이 뜨지 않는다.

### 조건 확인은 두 번
- "특정 Wi-Fi일 때만 동작" 같은 조건은 시작할 때와 실제 변경 직전에 한 번씩 확인한다. 대기하는 사이에 상태가 바뀔 수 있다.
- SSID 이름만으로는 같은 이름의 다른 네트워크를 구분하지 못한다. 필요하면 내부에서만 풀리는 DNS 이름 조회 같은 확인을 추가한다.

## 예시
```powershell
# 등록 (관리자 PowerShell)
$action  = New-ScheduledTaskAction -Execute 'powershell.exe' `
           -Argument '-NoProfile -ExecutionPolicy Bypass -File "C:\ProgramData\MyTask\run.ps1"'
$setting = New-ScheduledTaskSettingsSet -ExecutionTimeLimit (New-TimeSpan -Minutes 1) -StartWhenAvailable
Register-ScheduledTask -TaskName 'MyTask' -Action $action -Settings $setting -RunLevel Highest

# 실행 (일반 사용자, UAC 없음)
schtasks /run /tn "MyTask"

# 확인 / 제거
Get-ScheduledTask -TaskName 'MyTask'
Unregister-ScheduledTask -TaskName 'MyTask' -Confirm:$false
```

## 주의할 점
- 실행 시간 제한을 걸어 두면 스크립트가 멈춰도 작업이 계속 남지 않는다.
- 다른 PC에 배포할 때는 네트워크 인터페이스 이름, Wi-Fi 프로필, 고정 IP 값처럼 PC마다 다른 값을 먼저 맞춘다.
- 스크립트가 아무 일도 하지 않은 경우에는 로그를 남기지 않아야 주기 작업의 로그가 쓸모 있게 유지된다.
