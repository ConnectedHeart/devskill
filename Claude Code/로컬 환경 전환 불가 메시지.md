# 로컬 환경 전환 불가 메시지

> 분류: Claude Code · 최근 갱신: 2026-10-15

## 한 줄 요약
Claude 데스크톱 앱(Code 탭)의 "환경을 전환할 수 없습니다: 로컬 환경 항목을 더 이상 사용할 수 없습니다"는 세션을 만들 때 쓴 로컬 폴더·프리셋 정보가 앱 목록에 없을 때 나오며, 사이드바 프로젝트 옆 + 버튼으로 연 세션은 환경 칸이 잠겨 보여도 실제로는 그 폴더에서 로컬로 실행된다.

## 내용
### 메시지가 나오는 경우
- 세션을 만들 때 쓴 로컬 폴더나 프리셋이 삭제됐거나 이름·경로가 바뀐 경우
- 세션의 워크트리가 정리되어 없어진 경우
- 클라우드·원격 세션을 로컬로 돌리려는데 이 PC에 연결할 로컬 항목이 없는 경우
- 앱 업데이트·재시작으로 예전 환경 목록이 갱신된 경우

### 실제로 막힌 것인지 확인
- 프로젝트 폴더의 `.claude/settings.local.json` 같은 프로젝트 설정은 환경 선택을 막지 않는다. 메시지는 앱 쪽 상태다.
- 프로젝트 이름 옆 +로 새 세션을 열면 그 프로젝트 폴더(로컬)가 이미 정해진 상태라 환경 선택 칸이 비활성으로 보일 수 있다. 그대로 메시지를 보내면 로컬에서 실행된다. 세션 안에서 작업 폴더와 로컬 실행 여부를 확인하면 바로 알 수 있다.
- "새 세션을 Remote Control에 자동 연결" 설정이 켜져 있어도 로컬 선택과는 무관하다.

### 대처 순서
1. 앱을 완전히 종료했다가 다시 연다(환경 목록 갱신).
2. 새 세션에서 "다른 폴더 열기"로 폴더를 직접 다시 지정한다(폴더 신뢰 상태 재설정).
3. 프리셋을 썼다면 설정에서 그 프리셋이 아직 있는지 본다.
4. 다른 폴더에서도 로컬을 고를 수 없다면 조직 정책으로 로컬 실행이 막힌 경우다.

## 주의할 점
- 실제로 세션이 시작되지 않는 경우와 선택 칸만 잠긴 경우는 증상이 같아 보인다. 화면 캡처로 어떤 선택지가 비활성인지 확인해야 원인을 가를 수 있다.
