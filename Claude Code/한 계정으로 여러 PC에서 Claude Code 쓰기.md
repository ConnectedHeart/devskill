# 한 계정으로 여러 PC에서 Claude Code 쓰기

> 분류: Claude Code · 최근 갱신: 2026-11-04

## 한 줄 요약
한 계정으로 여러 PC에서 Claude Code CLI를 동시에 써도 된다. 인증은 PC마다 따로 저장되고 사용량 한도는 계정 하나로 공유되며, 대화 기록과 `~/.claude/` 설정은 PC마다 따로다.

## 내용
- **로그인:** PC마다 `claude`를 실행해 같은 계정으로 로그인한다. 다른 PC에서 로그인해도 기존 PC가 로그아웃되지 않는다.
- **동시 실행:** 한 PC에서 터미널을 여러 개 띄우는 것과 같다.
- **사용량:** 구독 요금제는 계정 하나에 한도 하나라 여러 PC에서 쓰면 그만큼 빨리 소진된다. API 키는 같은 키 사용량으로 합산된다.
- **공유되지 않는 것:** 대화 기록과 `--resume`, `~/.claude/` 아래 설정·메모리·훅, 로컬 MCP 설정. 같은 환경이 필요하면 직접 복사·동기화한다.
- **따라오는 것:** 저장소에 커밋된 `CLAUDE.md`, `.claude/` 설정.
- **약관:** 본인이 여러 기기에서 쓰는 것은 괜찮지만 여러 사람이 계정 하나를 나눠 쓰는 것은 안 된다.

## 핵심 코드
```bash
claude            # 새 PC에서 실행 후 브라우저로 같은 계정 로그인
claude --resume   # 이 PC에서 했던 대화만 이어 갈 수 있음
```
```powershell
# 개인 설정을 다른 PC로 옮길 때 (비밀값이 든 파일은 빼고)
Copy-Item -Recurse "$HOME\.claude\settings.json","$HOME\.claude\CLAUDE.md" "<옮길 경로>"
```

## 주의할 점
- 훅·래퍼 스크립트·환경 변수가 특정 PC에만 있으면 다른 PC에서는 그 흐름이 돌지 않는다. 저장소 지침이 그 스크립트를 전제로 하면 PC마다 준비가 필요하다.
- 설정을 복사할 때 토큰·자격 증명 파일은 옮기지 말고 새 PC에서 다시 로그인한다.
