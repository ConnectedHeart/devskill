# 가로 메뉴 넘침 처리(폭을 재서 검색창 줄이고 메뉴 숨기기)

> 분류: 기타 · 최근 갱신: 2026-11-06

## 한 줄 요약
옆 패널을 드래그로 넓히는 화면에서는 상단 가로 메뉴의 가용 폭이 계속 바뀌므로, 화면 폭 기준 미디어쿼리 대신 폭이 바뀔 때마다 실제 너비를 재서 "검색창 축소 → 검색창 숨김 → 뒤 메뉴 숨기고 … 표시" 순으로 맞춘다.

## 내용
### 겹침의 원인
- 검색 입력창을 `position:absolute`로 왼쪽으로 펼쳐 두면, 레이아웃상 그 칸은 버튼 폭만 차지한다. 메뉴는 자리가 비었다고 보고 계속 그려져 입력창 밑에 깔린다. 넓은 화면에서는 틈이 있어 안 보이다가, 패널을 열어 좁아지면 마지막 메뉴가 반쯤 가려진다.
- 칸이 입력창 폭만큼 자리를 차지하게만 바꾸면 겹침은 없어지지만, 메뉴 영역이 한 줄 높이로 고정돼 있으면 넘친 메뉴가 **표시 없이 통째로 사라진다**. 사용자가 그 메뉴로 갈 방법이 없어지므로 고친 것으로 보기 어렵다.

### 왜 실측해야 하나
- 사용자마다 권한으로 메뉴 개수가 다르고, 언어마다 메뉴 이름 길이가 다르다. 기준 폭 하나로는 맞출 수 없다.
- 패널 드래그 중에는 폭이 연속으로 바뀐다. 패널을 "열 때" 한 번 처리하면 드래그 뒤 다시 깨진다.

### 단계
1. 검색창 폭을 최대에서 최소까지 줄인다.
2. 그래도 안 들어가면 검색창을 숨기거나 아이콘으로 접는다.
3. 그래도 넘치면 뒤 메뉴부터 숨기고 "…"를 붙여, 누르면 전체 메뉴를 연다.
4. 넓어지면 역순으로 되돌린다.
- 재는 시점: 처음 그릴 때, 창 크기 변경, 패널 열기·닫기·드래그(ResizeObserver), 메뉴 순서 변경, 웹 글꼴 로드 완료. 드래그 중에는 `requestAnimationFrame`으로 프레임당 한 번만.
- 메뉴 너비 합에는 **항목 사이 여백(margin)**까지 넣는다. 빼먹으면 일부 폭에서 겹친다.
- 메뉴 이름이 두 줄로 꺾이지 않게 `white-space: nowrap`. 드래그 중 깜빡임을 막으려면 검색창 폭 전환 애니메이션을 끈다.

## 핵심 코드
### 1) 맞추기 함수
```javascript
// 바꿔야 할 곳: 선택자, 검색창 최대·최소 폭
function fitTopMenu() {
  const bar = document.querySelector('.top-bar');
  const items = [...bar.querySelectorAll('.menu > li:not(.more)')];
  const search = bar.querySelector('.search'), more = bar.querySelector('.menu > li.more');
  items.forEach(li => li.classList.remove('hidden')); more.hidden = true;
  search.hidden = false; search.style.width = '250px';

  const outer = li => { const s = getComputedStyle(li);
    return li.offsetWidth + parseFloat(s.marginLeft) + parseFloat(s.marginRight); };   // 여백 포함
  const fixed = bar.querySelector('.logo').offsetWidth + bar.querySelector('.right').offsetWidth;
  let room = bar.clientWidth - fixed - items.reduce((a, li) => a + outer(li), 0);

  if (room < 250) { const w = Math.max(150, 250 + room); search.style.width = w + 'px'; room -= (w - 250); }
  if (room < 0)   { search.hidden = true; room += parseFloat(search.style.width); }
  if (room < 0)   { more.hidden = false; room -= outer(more);
    for (let i = items.length - 1; i >= 0 && room < 0; i--) { room += outer(items[i]); items[i].classList.add('hidden'); } }
}
```

### 2) 폭 변화에 반응 (프레임당 한 번)
```javascript
let pending = false;
const schedule = () => { if (!pending) { pending = true; requestAnimationFrame(() => { pending = false; fitTopMenu(); }); } };
new ResizeObserver(schedule).observe(document.querySelector('.top-bar'));
window.addEventListener('resize', schedule);
document.fonts && document.fonts.ready.then(schedule);            // 웹 글꼴이 늦게 적용될 때
document.querySelector('.menu > li.more').addEventListener('click', e => { e.stopPropagation(); openAllMenu(); });
```

### 3) CSS
```css
.top-bar .menu > li { white-space: nowrap; }
.top-bar .menu > li.hidden { display: none; }
.top-bar .search { transition: none; }   /* 드래그 중 겹침 방지 */
```

## 주의할 점
- 화면이 iframe으로 나뉘어 있으면 패널 드래그로 바뀌는 것은 메뉴 프레임의 폭이다. 그 프레임 안에서 `resize`·ResizeObserver로 받는다.
- "…"를 누를 때 메뉴 영역의 다른 클릭 동작(닫기 등)이 같이 실행되지 않게 전파를 막는다.
- 재현 페이지에서 확인할 때는 글꼴·아이콘이 실제와 달라 단계가 바뀌는 폭이 조금 다를 수 있다. 실제 화면에서 패널 폭을 최소~최대로 끌어 보며 확인한다.
