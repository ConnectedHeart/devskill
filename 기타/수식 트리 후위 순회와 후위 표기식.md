# 수식 트리 후위 순회와 후위 표기식

> 분류: 기타 · 최근 갱신: 2026-11-16

## 한 줄 요약
수식 트리를 왼쪽 → 오른쪽 → 자기 자신 순(후위 순회)으로 방문하면 연산자가 피연산자 뒤에 붙는 후위 표기식이 나오고, 스택으로 다시 계산해 맞는지 확인할 수 있다.

## 내용
- 후위 순회는 모든 노드에서 **왼쪽 자식 → 오른쪽 자식 → 자기 자신**. 연산자 노드를 마지막에 방문하므로 "피연산자 두 개, 그다음 연산자" 순서가 된다.
- 예제 트리: 루트 `-`의 왼쪽 `A`, 오른쪽 `-`. 오른쪽 `-`의 왼쪽 `*`, 오른쪽 `E`. `*`의 왼쪽 `+`(B, C), 오른쪽 `D`.
  1. 루트에서 왼쪽 `A` → **A**
  2. 오른쪽 `-` → 그 왼쪽 `*` → 그 왼쪽 `+`에서 **B C +**
  3. `*`의 오른쪽 D, 그리고 `*` → **D \***
  4. 오른쪽 `-`의 오른쪽 E, 그리고 `-` → **E -**
  5. 루트 → **-**
- 결과 `A B C + D * E - -`, 중위식으로는 `A - ((B + C) * D - E)`.
- **검증**: 왼쪽부터 읽으며 피연산자는 push, 연산자는 두 개를 pop해 (먼저 꺼낸 것이 오른쪽) 계산한 뒤 push. 끝에 스택에 값 하나만 남고 원래 식과 같으면 올바르다.
- 전위(자기 → 왼 → 오)는 전위 표기(폴란드 표기), 중위(왼 → 자기 → 오)는 괄호를 더해야 원래 식이 된다.

## 핵심 코드
```java
// 후위 순회로 후위 표기식 만들기
record Node(String v, Node left, Node right) {}   // Java 16+ (8이면 일반 클래스)

static void postorder(Node n, StringBuilder out) {
    if (n == null) return;
    postorder(n.left(), out);
    postorder(n.right(), out);
    out.append(n.v()).append(' ');
}
```
```java
// 후위식 계산(검증): 피연산자 push, 연산자면 두 개 pop
static double eval(String[] tokens) {
    Deque<Double> st = new ArrayDeque<>();
    for (String t : tokens) {
        switch (t) {
            case "+": case "-": case "*": case "/": {
                double b = st.pop(), a = st.pop();      // 먼저 꺼낸 b가 오른쪽
                st.push(t.equals("+") ? a + b : t.equals("-") ? a - b : t.equals("*") ? a * b : a / b);
                break;
            }
            default: st.push(Double.parseDouble(t));
        }
    }
    if (st.size() != 1) throw new IllegalArgumentException("잘못된 후위식");
    return st.pop();
}
```

## 주의할 점
- `-`, `/`는 순서가 중요하다. pop한 두 값 중 나중에 꺼낸 것이 왼쪽 피연산자다.
- 계산이 끝났을 때 스택에 둘 이상 남거나, 연산자에서 꺼낼 값이 모자라면 식이 잘못된 것이다.
