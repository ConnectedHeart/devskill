# 달력 화면의 중복 동기 요청 없애기와 받은 응답 재사용

> 분류: 기타 · 최근 갱신: 2026-11-06

## 한 줄 요약
달력+목록 화면에서 함수가 넘겨받은 날짜 대신 화면 달력의 첫 칸~마지막 칸으로 요청 기간을 잡고 있다면, "오늘 목록"과 "달력 점" 요청이 사실 같은 요청이다. 첫 응답을 그대로 쓰고, 같은 달 안에서 날짜를 누를 때는 받아 둔 응답으로 목록만 다시 그리면 요청이 사라진다.

## 내용
### 알아보는 법
- 개발자 도구 네트워크 탭에서 같은 URL·같은 본문 요청이 진입 한 번에 두 번 나가는지 본다.
- 요청 함수가 인자로 받은 기간을 실제로 보내는지 확인한다. 화면 DOM(달력 칸의 data 속성)에서 기간을 다시 읽어 보낸다면 인자는 "목록에 보여 줄 날"을 고르는 데만 쓰인다.
- `async: false` 동기 요청이면 응답 동안 화면이 굳고, 애니메이션 콜백 뒤에 두 번째 요청을 보내면 "애니메이션 시간 + 요청 1회"만큼 늦게 표시된다.

### 고치는 방법
1. **진입**: 첫 응답(이미 한 달 전체)으로 목록과 달력 점·휴일을 바로 그리고, 펼침 애니메이션은 따로 돌린다.
2. **같은 달 날짜 클릭**: 직전 응답과 그 기간을 기억해 두고, 누른 날짜가 그 기간 안이면 응답에서 그날 것만 골라 그린다.
3. **다른 달로 이동**하면 새로 받는다. **상세·등록·수정 화면을 다녀오면** 데이터가 바뀌었을 수 있으니 기억을 버린다.
4. 날짜마다 접었다 펴는 애니메이션은 없애거나 줄인다.

### 지연 콜백의 숨은 버그
- 애니메이션 콜백(예: 400ms 뒤) 안에서 "지금 활성 화면"의 DOM을 다시 읽으면, 그 사이 사용자가 다른 화면으로 이동했을 때 다른 화면 기준으로 실행된다(달력이 없으면 `undefined` 오류). 응답 처리 함수 안의 지역 변수를 같은 흐름에서 바로 쓰면 이 틈이 없다.

## 핵심 코드
### 1) 진입: 첫 응답으로 바로 그리기
```javascript
function loadMonth(listDate) {
  const range = readCalendarRange();                 // 화면 달력 첫 칸~마지막 칸
  $.post('/api/events', range).done(function (res) {
    const data = res.events;                         // 이 콜백 안의 지역 변수
    renderList(data, listDate);
    renderDots(data);                                // 같은 기간을 다시 요청하지 않는다
    renderHolidays();
    cache = { range: range, data: data };            // 날짜 클릭 때 재사용
    $('.ui-page-active .list').slideDown(200);       // 애니메이션은 표시와 분리
  });
}
```

### 2) 같은 달 날짜 클릭은 요청 없이
```javascript
let cache = null;
function onDayClick(day) {
  if (cache && day >= cache.range.start && day <= cache.range.end) {
    renderList(cache.data, day);                     // 요청 0회
    return;
  }
  loadMonth(day);                                    // 다른 달이면 새로 받기
}
$(document).on('pagebeforeshow', '#detailPage, #editPage', () => { cache = null; });  // 수정 가능 화면 다녀오면 무효화
```

## 주의할 점
- 화면에 머무는 동안 다른 사람이 추가한 일정은 다른 달로 넘기거나 화면을 다시 열기 전까지 보이지 않는다. 받아 두는 범위를 화면 단위로 제한한다.
- 여러 화면이 같은 DOM 구조를 공유하면(jQuery Mobile 등) 선택자를 활성 페이지 범위로 한정한다.
- 동기 요청을 비동기로 바꿀 때는 그 결과에 기대는 뒤 코드를 콜백 안으로 옮긴다.
