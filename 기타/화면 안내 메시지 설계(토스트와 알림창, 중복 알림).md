# 화면 안내 메시지 설계(토스트와 알림창, 중복 알림)

> 분류: 기타 · 최근 갱신: 2026-10-27

## 한 줄 요약
반복 작업의 성공 안내는 작업을 막지 않는 토스트로, 사용자가 꼭 봐야 하는 실패는 알림창으로 띄우되, 알림은 호출하는 쪽에서 한 번만 한다. 하위 함수가 직접 알림을 띄우면 같은 실패가 두 번 뜨고 상태가 꼬인다.

## 내용
- **브라우저 기본 `alert()`는 작업을 멈춘다**: 교정 제안을 여러 개 적용하는 화면에서 적용할 때마다 알림창이 뜨면 매번 [확인]을 눌러야 한다. 성공 안내는 몇 초 뒤 사라지는 토스트(toastr 등 이미 쓰는 라이브러리)로 바꾼다. 같은 문구가 겹쳐 뜨지 않게 중복 방지 옵션을 켠다.
- **실패는 계속 알림창으로**: 사용자가 놓치면 안 되는 오류는 알림창으로 남긴다. 다만 한 번만.
- **하위 함수는 알리지 않고 결과만 돌려준다**: 낱말 교체 같은 하위 함수가 실패 시 직접 "관리자에게 문의하세요"를 띄우고, 호출한 쪽도 다시 "교체되지 않았습니다"를 띄우면 같은 실패가 두 번, 그것도 상황에 맞지 않는 문구로 뜬다. 하위 함수는 성공 여부(또는 바뀐 결과)만 돌려주고 예외는 콘솔에 남기며, 사용자 안내는 호출하는 쪽 한 곳에서 한다.
- **결과를 확인한 뒤 상태를 바꾼다**: 취소 함수가 교체 성공 여부를 보지 않고 "취소되었습니다"를 띄우고 적용 표시를 지우면, 실제 본문은 그대로인데 화면은 취소된 것처럼 바뀐다. 결과가 바뀌지 않았으면 실패만 알리고 표시·저장 상태는 그대로 둔다.
- **일괄 처리는 결과를 한 번에**: 여러 건을 처리하면서 실패마다 알리지 말고, 끝에 "N건 적용, 실패 M건"을 한 번 알린다.
- **존재하지 않는 함수 호출 점검**: 문구를 만드는 헬퍼가 코드베이스 어디에도 정의돼 있지 않으면 그 경로는 항상 예외로 끝난다. 화면에서 부를 수 없는 경로(버튼이 없는 기능)라면 지금은 증상이 없지만, 고칠 때 함께 정리한다.

## 핵심 코드

### 1) 하위 함수는 결과만, 안내는 호출하는 쪽 한 곳에서
```javascript
// 하위 함수: 알리지 않고 결과만
function replaceInBlock(html, from, to) {
  try { return html.replace(from, to); }
  catch (e) { console.error(e); return html; }   // 실패하면 원본 그대로
}

// 호출하는 쪽: 한 번만 안내
function applyFix(fix) {
  var before = getBody();
  var after = replaceInBlock(before, fix.from, fix.to);
  if (after === before) { alert('교체되지 않았습니다. 원문을 찾을 수 없습니다.'); return; }
  setBody(after);
  markApplied(fix);
  toastr.success('적용되었습니다.');
}
```

### 2) toastr 로드와 중복 방지 설정
```html
<!-- toastr 는 jQuery 가 먼저 로드돼 있어야 한다 -->
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/toastr.js/2.1.4/toastr.min.css">
<script src="https://cdnjs.cloudflare.com/ajax/libs/toastr.js/2.1.4/toastr.min.js"></script>
```
```javascript
toastr.options = {
  preventDuplicates: true,              // 같은 문구가 떠 있으면 다시 띄우지 않음
  timeOut: 2000,                        // 2초 뒤 사라짐
  positionClass: "toast-bottom-center"
};
toastr.success("적용되었습니다.");
```

### 3) 라이브러리 없는 간단한 토스트
```javascript
function toast(msg, ms) {
  var shown = document.querySelectorAll(".my-toast");
  for (var i = 0; i < shown.length; i++) if (shown[i].textContent === msg) return;   // 같은 문구 중복 방지
  var el = document.createElement("div");
  el.className = "my-toast";
  el.textContent = msg;
  document.body.appendChild(el);
  setTimeout(function () { el.parentNode && el.parentNode.removeChild(el); }, ms || 2000);
}
```
```css
.my-toast {
  position: fixed; left: 50%; bottom: 40px; transform: translateX(-50%);
  padding: 10px 16px; border-radius: 6px; z-index: 10000;
  background: rgba(0, 0, 0, .8); color: #fff;
}
```

### 4) 일괄 처리는 끝에 한 번만 알리기
```javascript
function applyAll(fixes) {
  var ok = 0, fail = 0, body = getBody();
  fixes.forEach(function (fix) {
    var after = replaceInBlock(body, fix.from, fix.to);
    if (after === body) { fail++; return; }       // 실패한 건은 표시·상태를 바꾸지 않는다
    body = after;
    markApplied(fix);
    ok++;
  });
  setBody(body);
  if (fail > 0) alert(ok + "건 적용, 실패 " + fail + "건");   // 놓치면 안 되는 결과는 알림창
  else toastr.success(ok + "건 적용되었습니다.");
}
```

### 5) 정의되지 않은 헬퍼 호출 찾기
```bash
# 바꿔야 할 곳: makeMessage → 의심되는 함수 이름
grep -rn "makeMessage(" --include='*.js' --include='*.jsp' --include='*.html' .        # 호출하는 곳
grep -rnE "function +makeMessage|makeMessage *[:=] *function" \
     --include='*.js' --include='*.jsp' --include='*.html' .                            # 정의된 곳(없으면 항상 예외)
```

## 주의할 점
- 토스트 라이브러리는 이미 프로젝트에서 쓰는 것을 재사용하고, 그 화면에 스크립트·CSS가 로드돼 있는지 확인한다.
- 같은 팝업을 여러 화면이 공유하면 한 곳을 고친 것이 모두에 적용된다.
