# 브라우저 마이크 녹음 기능을 붙일 때 확인할 것

> 분류: 기타 · 최근 갱신: 2026-10-27

## 한 줄 요약
웹(특히 모바일 웹·하이브리드 앱)에 실시간 녹음을 붙일 때는 코드보다 환경 조건이 먼저 막힌다. https, 앱 웹뷰의 마이크 권한, 프록시의 WebSocket 업그레이드, 다중 서버의 고정 세션을 먼저 확인해야 한다.

## 내용
### 브라우저·앱 조건
- `getUserMedia`(마이크)는 보안 컨텍스트, 즉 https나 localhost에서만 동작한다. http 운영 주소에서는 `navigator.mediaDevices` 자체가 없어 권한 창조차 뜨지 않는다. 이때는 "이 기기에서 녹음할 수 없음" 같은 안내를 띄운다.
- 하이브리드 앱이면 웹뷰가 페이지에 마이크 권한을 넘겨줘야 한다. 이것은 웹 코드로 해결할 수 없어 앱 쪽 작업이 필요하다.
  - 권한은 두 단계다. ① OS가 앱에 마이크를 허락하고, ② 앱(웹뷰)이 웹 페이지의 요청을 허락한다. 일반 브라우저는 두 단계를 이미 갖추고 있지만, 웹뷰는 앱이 처리 코드를 넣지 않으면 페이지 요청을 기본으로 거부한다.
  - 안드로이드: `AndroidManifest.xml`에 `RECORD_AUDIO`(필요하면 `MODIFY_AUDIO_SETTINGS`)를 선언하고, 안드로이드 6 이상은 실행 중에 사용자에게 권한을 요청한다. 그리고 `WebChromeClient.onPermissionRequest`를 재정의해 `PermissionRequest.RESOURCE_AUDIO_CAPTURE` 요청을 `request.grant(...)`로 허락한다.
  - iOS: `Info.plist`에 `NSMicrophoneUsageDescription`(사용 목적 문구)이 있어야 한다. WKWebView의 `getUserMedia`는 iOS 14.3부터 동작하고, iOS 15부터는 `WKUIDelegate`의 `requestMediaCapturePermissionFor…`로 페이지 요청을 허락하거나 거부한다. 처리하지 않으면 매번 시스템 확인 창이 뜬다.
  - 구분법: 같은 주소를 휴대폰의 일반 브라우저(Chrome·Safari)로 열어 본다. 브라우저에서도 안 되면 웹 쪽(먼저 https) 문제이고, 브라우저에서는 되는데 앱에서만 권한 창 없이 바로 `NotAllowedError`가 나면 앱 쪽 작업이 필요하다.
- iOS Safari·웹뷰는 `AudioContext`를 사용자 탭 이벤트 안에서 만들고 `resume()`해야 소리가 들어온다. 녹음 시작 버튼 처리 안에서 바로 만든다.
- 마이크를 먼저 열고, 성공한 뒤에 서버 소켓을 연다. 권한이 거부되면 서버 연결을 만들 필요가 없다.
- 녹음 중 화면을 닫거나 뒤로 가면 `MediaStreamTrack.stop()`으로 마이크를 끄고 소켓을 닫는다. 이 처리가 없으면 화면을 떠난 뒤에도 녹음이 계속 살아 있는 경우가 있다(SPA·jQuery Mobile처럼 이전 화면 DOM이 남는 구조에서 특히).

### 실시간 전송 구조
- 브라우저 → 화면 서버 → 내부 API 서버 → 음성인식 서버처럼 여러 단을 WebSocket으로 중계할 때가 많다. 각 단의 송신은 전용 스레드·큐로 처리하고, 큐가 밀리면 음성 조각을 버리는 정책을 정해 둔다(실시간 음성은 늦게 도착하면 쓸모가 없다). 그래야 한 단이 느려도 전체가 멈추지 않는다. 설정 메시지 같은 제어 메시지는 버리지 않는다.
- 한쪽 연결이 끊기면 반대쪽도 끊는다. 한쪽만 살아 있으면 화면은 녹음이 멈춘 것을 알 수 없다.
- WebSocket 핸드셰이크에서는 쿠키나 IP 같은 기존 인증 수단을 쓰기 어려운 경우가 있다(쿠키는 업그레이드 요청에만 실려 오고, 표준 JSR-356 API로는 접속 IP를 알 수 없으며, 스프링 인터셉터도 타지 않는다). 그럴 때는 인증된 REST 호출로 **짧은 수명(예: 1분)의 티켓**을 발급받아 연결 시 제출하게 한다.
  - 티켓을 암호화만 하고 무결성 값(HMAC 등)을 붙이지 않으면 위변조 검증이 약해진다. 서명을 붙이고, 형식 검사와 만료 검사를 한다.
  - 티켓을 서버 메모리에 저장하지 않으면 서버가 여러 대여도 어디서나 검증되지만, 만료 전에는 재사용할 수 있다. 엄밀한 1회용이 필요하면 티켓의 임의값을 DB 같은 공용 저장소에 "사용됨"으로 남긴다.
- 녹음 기능은 PC와 모바일이 같은 중계 로직을 쓰도록 공용 클래스로 뺀다. 그래야 종료 순서나 오류 처리가 어긋나지 않는다. 엔드포인트마다 다른 것은 "사용자 확인 방법"(쿠키 / 티켓)뿐이게 만든다.
- 저장 경로 같은 서버 자원 위치는 화면이 보낸 값을 쓰지 않고 서버가 조립한다. 화면이 보낸 ID가 파일 이름이 되면 형식(정규식)을 검사한다.

### 운영 환경
- 앞단 프록시(웹서버, L7)에서 해당 경로의 `Upgrade: websocket`을 허용해야 한다. 유휴 타임아웃이 짧으면 말이 없는 구간에 끊기므로, 서버가 주기적으로(예: 20초) ping을 보내고 프록시 타임아웃은 그보다 길게 둔다.
- 서버가 여러 대이면, 연결이 유지되는 동안 같은 서버로 가도록 L4/L7에서 고정 세션(sticky)을 설정해야 할 수 있다.

### 1) 브라우저: 지원 확인 → 마이크 → 16kHz PCM16 → WebSocket
```javascript
// 녹음 시작 버튼 클릭 처리 안에서 호출한다(iOS 는 AudioContext 를 탭 이벤트 안에서 만들어야 함)
function startRecording(wsUrl /* 예: "wss://example.com/ws/record?ticket=..." */) {
  const AudioCtx = window.AudioContext || window.webkitAudioContext;
  if (!navigator.mediaDevices || !navigator.mediaDevices.getUserMedia || !AudioCtx) {
    alert("이 기기(또는 http 접속)에서는 녹음할 수 없습니다."); return;
  }
  const rec = { ctx: new AudioCtx() };
  if (rec.ctx.state === "suspended") rec.ctx.resume();

  navigator.mediaDevices.getUserMedia({ audio: true }).then((stream) => {
    rec.stream = stream;                                   // 마이크가 열린 뒤에 소켓을 연다
    rec.socket = new WebSocket(wsUrl);
    rec.socket.binaryType = "arraybuffer";
    rec.socket.onopen = () => {
      rec.socket.send(JSON.stringify({ lang: "ko" }));     // 첫 메시지는 설정(JSON), 이후는 음성(바이너리)
      const src = rec.ctx.createMediaStreamSource(stream);
      rec.proc = rec.ctx.createScriptProcessor(4096, 1, 1); // 새로 만들면 AudioWorklet 권장
      src.connect(rec.proc); rec.proc.connect(rec.ctx.destination); // 연결해야 onaudioprocess 가 돈다
      rec.proc.onaudioprocess = (e) => {
        if (rec.socket.readyState !== WebSocket.OPEN) return;
        const pcm = toPcm16(downsample(e.inputBuffer.getChannelData(0), rec.ctx.sampleRate, 16000));
        rec.socket.send(pcm);
      };
    };
    rec.socket.onmessage = (e) => { if (typeof e.data === "string") showTranscript(JSON.parse(e.data)); };
    rec.socket.onclose = () => stopRecording(rec);          // 서버가 끊어도 마이크를 끈다
  }).catch((err) => {
    rec.ctx.close();
    const msg = { NotAllowedError: "마이크 권한이 거부되었습니다(앱이면 웹뷰 권한 확인).",
                  NotFoundError: "마이크가 없습니다.", NotReadableError: "다른 앱이 마이크를 쓰는 중입니다." };
    alert(msg[err.name] || "마이크를 열 수 없습니다.");
  });
  return rec;
}
```

```javascript
function downsample(buf, inRate, outRate) {   // 단순 샘플 추출(품질이 중요하면 평균·필터 사용)
  if (outRate >= inRate) return buf;
  const ratio = inRate / outRate, out = new Float32Array(Math.floor(buf.length / ratio));
  for (let i = 0; i < out.length; i++) out[i] = buf[Math.floor(i * ratio)];
  return out;
}
function toPcm16(f32) {                        // Float32(-1~1) → 16비트 little-endian
  const view = new DataView(new ArrayBuffer(f32.length * 2));
  for (let i = 0; i < f32.length; i++) {
    const s = Math.max(-1, Math.min(1, f32[i]));
    view.setInt16(i * 2, s < 0 ? s * 0x8000 : s * 0x7fff, true);
  }
  return view.buffer;
}
function stopRecording(rec) {                  // 일시중지·화면 이탈·서버 종료 모두 여기로
  if (rec.proc) { rec.proc.onaudioprocess = null; rec.proc.disconnect(); }
  if (rec.stream) rec.stream.getTracks().forEach((t) => t.stop());   // 마이크 표시등이 꺼져야 정상
  if (rec.ctx && rec.ctx.state !== "closed") rec.ctx.close();
  if (rec.socket && rec.socket.readyState <= 1) rec.socket.close();
}
window.addEventListener("pagehide", () => currentRec && stopRecording(currentRec));
```

```kotlin
private var pendingRequest: PermissionRequest? = null
private val REQ_MIC = 1001

webView.webChromeClient = object : WebChromeClient() {
    override fun onPermissionRequest(request: PermissionRequest) {
        val wantsMic = request.resources.contains(PermissionRequest.RESOURCE_AUDIO_CAPTURE)
        if (!wantsMic || request.origin.host != "app.example.com") { request.deny(); return }  // 내 사이트만 허락
        if (ContextCompat.checkSelfPermission(this@MainActivity, Manifest.permission.RECORD_AUDIO)
                == PackageManager.PERMISSION_GRANTED) {
            request.grant(arrayOf(PermissionRequest.RESOURCE_AUDIO_CAPTURE))
        } else {                                           // 앱 자체 권한부터 받는다(안드로이드 6+)
            pendingRequest = request
            ActivityCompat.requestPermissions(this@MainActivity, arrayOf(Manifest.permission.RECORD_AUDIO), REQ_MIC)
        }
    }
}

override fun onRequestPermissionsResult(code: Int, perms: Array<String>, results: IntArray) {
    super.onRequestPermissionsResult(code, perms, results)
    if (code != REQ_MIC) return
    val ok = results.firstOrNull() == PackageManager.PERMISSION_GRANTED
    pendingRequest?.let { if (ok) it.grant(arrayOf(PermissionRequest.RESOURCE_AUDIO_CAPTURE)) else it.deny() }
    pendingRequest = null
}
```

### 4) Java 서버(JSR-356): 핸드셰이크 쿠키로 사용자 확인 + ping
```java
@ServerEndpoint(value = "/ws/record", configurator = RecordEndpoint.CookieConfigurator.class)
public class RecordEndpoint {
    private static final ScheduledExecutorService PINGER = Executors.newScheduledThreadPool(1);
    private ScheduledFuture<?> ping;

    @OnOpen
    public void onOpen(Session session) throws IOException {
        String cookie = (String) session.getUserProperties().get("authCookie");
        String userId = AuthService.resolveUser(cookie);          // 직접 구현: 쿠키 → 사용자, 실패 시 null
        if (userId == null) {
            session.close(new CloseReason(CloseReason.CloseCodes.VIOLATED_POLICY, "login required"));
            return;
        }
        session.setMaxIdleTimeout(30 * 60 * 1000L);
        session.setMaxBinaryMessageBufferSize(4 * 1024 * 1024);
        ping = PINGER.scheduleAtFixedRate(() -> {                 // 프록시 유휴 타임아웃 방지
            try { if (session.isOpen()) session.getAsyncRemote().sendPing(ByteBuffer.allocate(0)); }
            catch (Exception ignore) { }                           // 전송 중이면 다음 주기에
        }, 20, 20, TimeUnit.SECONDS);
    }

    @OnClose
    public void onClose(Session session) { if (ping != null) ping.cancel(true); }

    /** 쿠키는 업그레이드 요청에만 있으므로 핸드셰이크에서 꺼내 둔다 */
    public static class CookieConfigurator extends ServerEndpointConfig.Configurator {
        @Override
        public void modifyHandshake(ServerEndpointConfig config, HandshakeRequest req, HandshakeResponse res) {
            for (Map.Entry<String, List<String>> h : req.getHeaders().entrySet()) {
                if (!"cookie".equalsIgnoreCase(h.getKey())) continue;     // 헤더 이름 대소문자는 컨테이너마다 다르다
                for (String line : h.getValue()) for (String pair : line.split(";")) {
                    String[] kv = pair.trim().split("=", 2);
                    if (kv.length == 2 && "AUTH".equals(kv[0])) config.getUserProperties().put("authCookie", kv[1]);
                }
            }
        }
    }
}
```

### 5) 중계: 전용 송신 스레드 + 밀리면 버리기 (Java 클라이언트 쪽 연결)
```java
@ClientEndpoint
public class UpstreamRelay {
    private final Session browser;                     // 브라우저 쪽 세션
    private volatile Session upstream;                 // 다음 단(음성인식 서버 등)
    private final ExecutorService sender = Executors.newSingleThreadExecutor();
    private final AtomicInteger pending = new AtomicInteger();

    public UpstreamRelay(Session browser) { this.browser = browser; }

    public void connect(URI uri) throws Exception {
        upstream = ContainerProvider.getWebSocketContainer().connectToServer(this, uri);
        // Tomcat 전용: 한 번의 블로킹 전송 대기 한도(기본 20초) 줄이기
        upstream.getUserProperties().put("org.apache.tomcat.websocket.BLOCKING_SEND_TIMEOUT", 2000L);
    }

    public void forwardAudio(ByteBuffer data) {
        if (pending.get() >= 50) return;               // 밀리면 음성 조각은 버린다(제어 메시지는 버리지 않는다)
        byte[] copy = new byte[data.remaining()];
        data.get(copy);                                // 컨테이너가 버퍼를 재사용하므로 복사
        pending.incrementAndGet();
        sender.execute(() -> {
            try { Session s = upstream; if (s != null && s.isOpen()) s.getBasicRemote().sendBinary(ByteBuffer.wrap(copy)); }
            catch (IOException e) { /* 연속 실패 횟수를 세어 일정 횟수 넘으면 양쪽을 끊는다 */ }
            finally { pending.decrementAndGet(); }
        });
    }

    @OnMessage
    public void onUpstreamText(String json) { if (browser.isOpen()) browser.getAsyncRemote().sendText(json); }

    @OnClose
    public void onUpstreamClose() {                    // 한쪽이 끊기면 반대쪽도 끊는다
        try { if (browser.isOpen()) browser.close(new CloseReason(CloseReason.CloseCodes.GOING_AWAY, "upstream closed")); }
        catch (IOException ignore) { }
    }

    public void close() {
        sender.shutdownNow();
        try { Session s = upstream; upstream = null; if (s != null) s.close(); } catch (IOException ignore) { }
    }
}
```

### 6) 짧은 수명 티켓: 발급·검증 (HMAC 서명, Java 8)
```java
public final class WsTicket {
    private static final long TTL_MS = 60_000L;

    /** 인증된 REST 요청 안에서 발급 → 응답으로 돌려준다 */
    public static String issue(byte[] key, String userId) throws Exception {
        if (userId.contains("|")) throw new IllegalArgumentException("bad user id");
        String payload = userId + "|" + (System.currentTimeMillis() + TTL_MS) + "|" + UUID.randomUUID();
        String body = b64(payload.getBytes(StandardCharsets.UTF_8));
        return body + "." + b64(hmac(key, body));
    }

    /** 소켓 onOpen 에서 검증. 통과하면 사용자 ID, 아니면 null */
    public static String verify(byte[] key, String ticket) {
        try {
            String[] p = ticket.split("\\.", 2);
            if (p.length != 2 || !MessageDigest.isEqual(hmac(key, p[0]), Base64.getUrlDecoder().decode(p[1]))) return null;
            String[] f = new String(Base64.getUrlDecoder().decode(p[0]), StandardCharsets.UTF_8).split("\\|");
            if (f.length != 3 || Long.parseLong(f[1]) < System.currentTimeMillis()) return null;
            return f[0];   // 1회용이 필요하면 f[2](UUID)를 공용 저장소에 "사용됨"으로 남기고 재사용을 거부
        } catch (Exception e) {
            return null;
        }
    }

    private static byte[] hmac(byte[] key, String s) throws Exception {
        Mac mac = Mac.getInstance("HmacSHA256");
        mac.init(new SecretKeySpec(key, "HmacSHA256"));
        return mac.doFinal(s.getBytes(StandardCharsets.UTF_8));
    }
    private static String b64(byte[] b) { return Base64.getUrlEncoder().withoutPadding().encodeToString(b); }
}
```

### 8) 일시중지 뒤 "파일이 실제로 생겼는지" 확인하고 저장
```javascript
// 소켓을 닫은 뒤 서버(또는 음성인식 서버)가 파일을 마무리할 때까지 짧게 되묻는다
function waitForFile(checkUrl, baseline, done, tries = 30) {
  fetch(checkUrl).then((r) => r.json()).then((f) => {
    const changed = f.exists && (!baseline || f.size !== baseline.size || f.modified !== baseline.modified);
    if (changed) return done(true);                       // 이번 녹음으로 바뀐 파일일 때만 임시저장
    if (tries <= 1) return done(false);
    setTimeout(() => waitForFile(checkUrl, baseline, done, tries - 1), 500);
  }).catch(() => done(false));
}
```

## 주의할 점
- 일시중지 시 자동 임시저장 같은 기능은 "녹음 파일이 실제로 생겼는지" 서버에 확인한 뒤 저장해야 빈 기록이 남지 않는다. 녹음 시작 때 파일 크기·수정 시각을 기억해 두면 이번 녹음으로 바뀐 파일인지 가릴 수 있다.
- 모바일 브라우저마다 지원하는 오디오 코덱이 다르다. 재생까지 고려하면 서버에서 범용 형식으로 저장한다.
- `createScriptProcessor`는 사용 중단 예정 API다. 지금도 대부분 동작하지만 새로 만들면 `AudioWorklet`을 검토한다.
- JSR-356의 `modifyHandshake`에서 `config.getUserProperties()`에 넣는 값은 컨테이너에 따라 연결끼리 공유될 수 있다(Tomcat은 연결마다 복사한다). 다른 컨테이너를 쓰면 동시 접속 때 값이 섞이지 않는지 확인한다.
- `@ServerEndpoint` 클래스는 스프링이 만들지 않으므로 `@Autowired`가 동작하지 않는다. 루트 컨텍스트에서 빈을 꺼내거나(`ContextLoader.getCurrentWebApplicationContext()`) `SpringConfigurator`를 쓴다.
